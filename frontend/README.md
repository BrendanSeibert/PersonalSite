# EX3 frontend

The React 19 + Vite app. See the repository's `README.md` for setup, and `CLAUDE.md` for the conventions.

- `npm run dev`: the dev server (normally started by `docker compose up` from the root)
- `npm test`: type check and unit tests (jsdom), 90% coverage
- `npm run test:browser`: browser tests in headless Chromium
- `npm run lint`: oxlint
- `npm run build`: production build into `dist/`
